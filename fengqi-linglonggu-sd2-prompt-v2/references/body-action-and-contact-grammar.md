## 1. 使用契约

- 当剧情出现走、跑、跪、抱、打斗、手部特写、饮茶饮酒、转身回头、对峙、诀别、重逢或掌掴，读取本文件。
- 先从人物档案解析角色的稳定性格和身体状态，再选择动作卡；不要让动作卡把所有人物写成同一种表演。
- 最终提示词必须写可见状态变化，不能只写“从容地走”“愤怒地打”“悲伤地抱”。
- 6-10 秒单镜默认一个主动作、3-5 个可见状态；复杂打斗、多人接触或多次方向变化必须拆镜。
- 最终提示词不得保留“或”“均可”“任选”“A/B”与未替换占位符。根据剧情、人物和机位解析为一个确定方案。
- 动作必须服从古装服饰、长袖、袍摆、腰封、发冠、簪钗、兵器和场景材质，不得出现现代场所、现代照明或现代生活物件。
- 头发、衣摆、袖口、雨雪、液体和道具必须由人物动作或环境力触发，不得先于主动作无因运动。
- 本文件不替代主技能的摄影协议。每个声明镜头仍须先写规范镜头头部，再写本文件生成的表演、动作与承接；共享捕获和光影参数只写入全局母版一次。

## 2. 调用顺序与优先级

执行顺序：

```text
角色名/别名解析
→ 人物稳定性格与习惯
→ 当前剧情动作、伤情和体力
→ 当前关系与情绪
→ 选择 A01-A12 动作卡
→ 用性格参数改写速度、幅度和回收
→ 锁定重心、左右手、双人距离、接触点和终点姿态
→ 选择本镜 3-6 条专属负面
→ 在本镜规范头部之后写入完整表演/动作/承接
```

冲突时采用以下优先级：

```text
剧情明确动作与身体伤情
> 当前人物关系与即时情绪
> 人物档案中的稳定性格
> 动作卡默认节奏
```

人物性格可以改变动作的速度、幅度、预备时间、接触强度和回收方式，但不得破坏支撑脚、关节先后、接触点、受力方向或镜头连续性。

## 3. 统一动作母语法

每个动作按以下七段组织：

```text
起始锚点
→ 准备动作
→ 动力链
→ 主动作/接触
→ 受力响应
→ 余势
→ 回收/终点锚点
```

### 3.1 七段定义

1. **起始锚点**：人物左右站位、身体朝向、支撑脚、前导脚、持物手、道具方向、双人距离、起始目光。
2. **准备动作**：先看哪里、吸气或屏息、哪个关节预载、重心向哪只脚或哪个方向偏移。
3. **动力链**：力量从脚掌、膝、髋、腰、肩、肘、腕到手指的先后；小动作只写实际参与的关节。
4. **主动作/接触**：唯一主要事件、明确方向和幅度；双人动作必须写主动者、接触点与受力者。
5. **受力响应**：身体、头部、肩线、步伐或道具按照接触方向作出因果一致的反应。
6. **余势**：发丝、袍摆、袖口、佩饰、雨雪、杯中液体在主动作之后延迟半拍摆动或震颤。
7. **回收/终点锚点**：手脚回到哪里、重心如何重新落稳、目光停在哪里、呼吸怎样结束；此状态必须能直接作为下一镜起点。

### 3.2 可直接调用的动作母句

```text
先锁定人物的起始站位、朝向、支撑脚、持物手和目光；准备时写清吸气、关节预载与重心偏移；主动作必须由明确动力链驱动，并写出方向、幅度和唯一接触点；受力者按同一力向回应，衣摆、袖口、发丝和道具在主动作之后延迟半拍形成余势；最后写明手脚回收、呼吸、结束距离与终点姿态，使该终点能直接承接下一镜。
```

### 3.3 动作节拍模板

```text
状态 1：起始锚点与视线。
状态 2：准备动作与重心变化。
状态 3：唯一主动作或接触。
状态 4：受力响应与衣发余势。
状态 5：回收、呼吸与终点锚点。
```

## 4. 人物性格的八种覆盖参数

人物档案应把抽象性格转换为以下八个可见参数：

| 参数 | 必须解析的问题 | 可见写法 |
|---|---|---|
| 动作速度 | 起动慢、均匀还是骤发 | 延迟半拍起动；匀速推进；短促爆发后硬停 |
| 动作幅度 | 动作收敛还是外放 | 只动眼与指尖；小幅转肩；大步前压 |
| 重心习惯 | 挺拔、低重心、前倾还是护伤 | 双脚均匀承重；重心压低；身体微前倾；一手护住伤处 |
| 视线顺序 | 眼、头、身体谁先动 | 眼先移、头后转；始终直视；先回避再抬眼 |
| 呼吸节律 | 平稳、屏息、浅急还是长吐气 | 吸气停住；短促喘息；完成动作后长吐气 |
| 手部习惯 | 手收在哪里、怎样碰物 | 手藏袖中；指尖轻扣；攥衣；开放掌心；握物不松 |
| 社交距离 | 主动靠近、守距还是后撤 | 保持一臂；斜向靠近；接触后立即退开 |
| 回收方式 | 干净、迟疑、发抖还是脱力 | 动作完成即停；手伸到半途收回；指尖余怒发颤；手臂脱力垂落 |

### 4.1 常用性格修饰器

- **克制沉稳**：预备更慢、幅度更小、重心稳定、停顿清楚，情绪落在目光、呼吸和手指。
- **敏捷警觉**：眼神先扫描，身体随后转向；重心轻、换步快，手先处理现实物件或风险。
- **骄矜权势**：脊柱挺直、下颌微抬、步幅受控，几乎没有多余摆臂；逼近只用半步。
- **受伤虚弱**：低重心、保护伤处、换重心延迟、浅呼吸，动作回收后出现短暂失力。
- **冲动暴烈**：预备短、幅度大、由脚和髋驱动，动作硬停，胸口或手指在结束后仍颤。
- **温柔照料**：斜向靠近、掌心开放、接触轻、停留较久，松开时指尖最后离开。
- **隐忍悲恸**：起动延迟、肩线缓慢下沉、手部失力，眼神比身体晚收回。
- **决绝冷硬**：目光先锁定，动作路径干净，无多余回望，终点重心稳且不反复。

## 5. 身体控制协议

### 5.1 重心

- 每个全身或半身动作写明起始承重：双脚均匀、左脚、右脚、前脚或后脚。
- 写明重心路径：垂直下沉、向前推进、横向避让、由后脚移至前脚或重新回到双脚之间。
- 跪、跑、打斗、承接拥抱和急停必须写重心；否则容易出现漂浮、滑步和比例突变。
- 终点必须重新落稳，除非剧情明确要求跌倒、失衡或被拖走。

### 5.2 脚步

- 锁定前导脚、支撑脚、步数、移动方向和最终落点。
- 正常行走使用对侧摆臂；跑动使用后脚蹬地、髋前送、清楚落脚。
- 转身先由支撑脚掌改变方向，再由髋腰和肩线跟进；禁止脚底不动而全身原地滑旋。
- 双人接触前写清最后一步：迈近、错步承接、半步逼近、后撤或原地钉住。

### 5.3 肩胯与躯干

- 大动作通常由脚和髋启动，肩线随后传力；手臂不能无躯干支持地突然甩出。
- 走跑时肩线保持可控，不随每一步夸张上下弹跳。
- 回头可只让眼、颈和上胸参与；完整转身必须让脚、髋、腰、肩、头依次跟进。
- 受击时头部先响应局部力，肩线晚半拍跟随；禁止整个人无因旋转或飞退。

### 5.4 肘、腕与手指

- 写明哪只手、肘部指向、腕部是否保持中立、手指如何收拢或松开。
- 持杯、持剑、执笔、递物必须写主手与辅助手的分工。
- 握拳时四指先收、拇指压在食指与中指外侧；不得把拇指包进拳心。
- 接触动作先建立掌心、指腹、指背、前臂或腕部的唯一接触点，再写施力和松开。
- 交握、拥抱和递物中，一方握稳后另一方才松开；禁止道具无支撑悬空。

### 5.5 视线与呼吸

- 视线可作为动作先导：先看、再转头、再移动身体或手。
- 对峙、追逐和打斗中写清目光对象；回眸不能让脚步和骨盆失去原方向。
- 屏息用于犹豫、恐惧、屈辱和出手前预载；吐气用于落地、放松、认命或动作回收。
- 饮茶饮酒写杯沿近唇停顿、吞咽和呼气；奔跑写呼吸加快但不替代落脚动作。

### 5.6 衣袂、发丝与佩饰

- 发丝、袍摆、长袖和佩饰比躯干晚半拍启动，比躯干晚半拍停下。
- 湿袍更重、摆幅更小；雪地衣摆受步伐和风共同影响，但风向必须固定。
- 转身、奔跑、掌掴和撞击后可写一次清楚余势，禁止持续无因飘动。
- 簪钗、发冠、腰封、玉佩和兵器位置必须跨镜保持一致，不得因动作变形或换侧。

## 6. 双人距离、接触点与受力

### 6.1 距离等级

| 距离 | 叙事用途 | 动作限制 |
|---|---|---|
| 两臂以上 | 观察、认出、追逐起点、诀别终点 | 无身体接触，用视线和移动方向建立关系 |
| 一臂半 | 对峙、谈判、出手前 | 可半步逼近，不得无因贴身 |
| 一臂 | 拥抱准备、递物、近战攻击距离 | 必须写谁先迈近以及最后一步落点 |
| 半臂 | 安慰、阻拦、近身控制 | 必须写手落在肩、上臂、前臂或腕部的具体位置 |
| 贴合 | 拥抱、承接、擒拿 | 必须锁定胸肩、肩窝、肩胛、上背等接触点和双方重心 |

### 6.2 常用接触规则

- **重逢拥抱**：接触点为胸肩、肩窝、肩胛和上背；承接者前后错步、屈膝吸收冲力。
- **安慰拥抱**：一手稳定上背，另一手轻拍肩胛；被安慰者的颤动发生在贴合之后。
- **告别拥抱**：先收紧，再延迟松开；指尖最后离开衣料，结束距离逐步拉开。
- **强迫拥抱/禁锢**：主动者向内收紧，抵抗者以前臂撑开或重心后撤；两组力向必须相反。
- **近身搏斗**：一次交锋只保留一个主要接触点，例如前臂格挡腕部、武器相接、肩部推开；受力方向与退步方向一致。
- **诀别挽留**：不发生接触；伸出的手停在离对方后肩半臂处，再迟疑收回。
- **掌掴**：明确施打手、受击脸侧和掌心接触区；头部先沿力向偏转，肩线和发丝晚半拍响应。

### 6.3 双人动作母句

```text
开场写清 A、B 的左右站位、朝向与距离；指定主动者先改变重心并迈出最后一步，指定唯一接触点与施力方向；受力者沿同一方向作出头、肩、躯干或脚步响应；双方衣袖和发丝在接触后延迟半拍产生余势；结束时锁定新的距离、手位、目光和站姿，禁止人物换边或接触点漂移。
```

## 7. 连续性锚点

每个动作镜头至少锁定以下必要项：

- 人物 A/B 的画面左右位置、朝向、视线轴和是否允许越轴。
- 起始支撑脚、前导脚、移动方向、步数或最终落点。
- 左右手分工、持物手、武器手、道具朝向和配饰位置。
- 双人开场距离、结束距离、主动者、受力者和唯一接触点。
- 被触碰或受击的脸侧、肩侧、手臂侧或身体侧。
- 衣摆、袖口、发丝、雨雪和道具的惯性方向。
- 终点手位、脚位、目光、呼吸和身体高度；下一镜从完全相同状态开始。

可直接附在镜头后的连续性模板：

```text
连续性锚点：A 位于画面{{左/右}}、B 位于画面{{右/左}}；A 以{{左/右}}脚承重，{{左/右}}手持{{道具}}；开场相距{{距离}}，主接触点为{{位置}}；动作结束时 A 停在{{位置与姿态}}、B 停在{{位置与姿态}}，衣发余势统一朝{{方向}}，下一镜不得换边、换手或改变接触侧。
```

## 8. 古装语境转译

最终提示词只输出古装实值，不输出转译前的现代例子。

| 不进入古装成片的元素 | 古装替代 |
|---|---|
| 机场、车站、现代站台 | 城门、驿站、宫道、院门、雪地长街 |
| 霓虹灯、现代路灯 | 灯笼、宫灯、檐灯、火把、烛火、纸窗透光 |
| 沥青湿路、现代街面 | 雨湿青石、宫墙甬道、石阶、雪地土路 |
| 现代玻璃杯、马克杯 | 白瓷盏、粗陶碗、青铜酒爵、玉杯 |
| 婚戒、现代饰品 | 指环、玉佩、发簪、香囊、腰牌、家传信物 |
| 现代书写姿势 | 非惯用手压纸、惯用手悬腕执笔、笔锋与宣纸接触 |
| 现代便服的轻薄摆动 | 长袖、袍摆、腰封、披风按面料重量形成延迟余势 |

古装动作还必须遵守：

- 长袖不能遮住所有关键接触点；必要时让袖缘退至腕部，露出手位。
- 宽袍转身时先由身体带动，袍摆随后掠过；禁止袍摆先转。
- 拔剑/刀时辅助手固定鞘口，主手沿鞘轴抽出；兵器不穿过衣袍或身体。
- 雨雪会改变衣料重量、落脚和地面摩擦；不得仍表现为现代影棚中无重量的飘纱。

## 9. A01-A12 动作卡

### A01 从容走路

- **适用**：出场、退场、巡视、转场、带压迫感的靠近。
- **起始与动力链**：后脚承重，目光先定；前脚落地，重心平顺前移，后脚跟进；双臂小幅对侧摆动。
- **余势与终点**：衣摆和发丝慢半拍摆开再回落；停步时双脚重新落稳。
- **性格覆盖**：克制者步幅小、肩线稳；权势者下颌微抬、摆臂更少；警觉者眼神先扫环境再继续行走；虚弱者换重心延迟并护住伤处。
- **古装可生成句式**：

```text
{{角色}}先将重心稳落在后脚，目光定住{{前方对象}}，随后以前脚落地、重心平顺前移、后脚跟进的节奏缓步而行；肩线平稳，双臂小幅反向摆动，衣摆与发丝慢半拍摆开再回落，最终在{{终点}}双脚站稳、呼吸平顺。
```

- **AI 风险**：同手同脚、脚底滑移、步长突变、肩线上下弹跳、人物未迈步却向前漂移、背景行人穿帮。

### A02 奔跑追逃

- **适用**：追击、逃离、急赴、带伤奔走。
- **起始与动力链**：上身微前倾，后脚蹬地，髋部前送；膝抬起并清楚落脚，双臂与步伐交替。
- **视线规则**：追者目光锁定前方；逃者可短促回眸，但骨盆和脚始终沿原路径。
- **余势与终点**：衣袂、发丝顺速度方向后扬；需要停下时以两步减速收住重心。
- **性格覆盖**：警觉者先扫退路再加速；决绝者不回头、路径笔直；恐惧者呼吸碎、回望短促；受伤者步频下降并以一手护伤。
- **古装可生成句式**：

```text
{{角色}}上身微前倾，后脚蹬地带动髋部前送，双臂与步伐交替摆动，沿{{固定方向}}全力奔跑；{{追者/逃者的视线行为}}，每一步落脚清楚，衣袂发丝顺速度方向后扬，抵达{{终点}}时用两步减速收住重心。
```

- **AI 风险**：漂浮跑、脚底打滑、四肢同向、回头造成躯干反拧、衣袂逆向、背景过度虚化导致空间消失。

### A03 下跪求饶与认命

- **适用**：求饶、请罪、屈辱、忏悔、认命、诀别礼跪。
- **起始与动力链**：吸气停住，膝髋屈曲，重心垂直下沉；一膝先触地，另一膝随后落稳。
- **手与上身**：手可撑地、压在腿侧或攥住衣摆；肩背按情绪塌下或绷紧。
- **性格覆盖**：求饶者抬眼、掌心开放；屈辱者下颌绷紧、手攥衣；认命者垂眼、长吐气；权势人物被迫下跪时脊背仍直、动作更慢。
- **古装可生成句式**：

```text
{{角色}}先屏住一口气，双膝屈曲、重心垂直下沉，一膝先触地，另一膝随后落稳；双手{{撑地/压在腿侧/攥住衣摆}}，肩背{{塌下/绷紧}}，目光{{抬向对方/垂落地面}}，半拍后颤着吐气，膝部贴地而不穿透青石或雪地。
```

- **AI 风险**：双腿融化式下沉、膝盖穿地、脚踝反折、袍摆卡入地面、身体高度或比例突变。

### A04 多情绪拥抱

- **适用**：重逢、安慰、告别、保护、禁锢。
- **基础接触链**：相隔一臂；主动者迈近张臂，承接者收步；一臂绕肩胛、一臂落上背，胸肩贴合，头停在肩窝。
- **情绪变体**：重逢为快速靠近、抱紧、呼吸破碎；安慰为慢靠近、稳定贴合、规律轻拍；告别为先加力、延迟松开、指尖最后离开；禁锢为主动者向内收紧、抵抗者以前臂撑开并后撤。
- **性格覆盖**：克制者先停顿才触碰，掌心轻落；冲动者靠近快但仍有清楚承接；温柔者斜向接近，避免正面撞击；疏离者接触短、先松手。
- **古装可生成句式**：

```text
两人开场相隔一臂，{{A}}先迈近并张臂，{{B}}顺势收步承接；{{A}}一臂绕至肩胛、一臂落在上背，二人胸肩真实贴合，头停在肩窝，收紧后停半拍，手掌{{轻拍后背/攥紧衣料}}，再{{缓缓松开/保持拥抱}}；左右手位和接触点全程不变。
```

- **AI 风险**：多余手臂或手指、手掌埋入背部、胸腹穿透、脸部融合、身高突变、双方手位互换。

### A05 近身搏斗

- **适用**：格挡、闪避、擒拿、推开、单次踢击或兵器短交锋。
- **执行限制**：一个镜头只保留一次主要攻防事件；快速剪辑和多角度必须拆成独立镜头。
- **起始与动力链**：防守者降低重心、前导脚落稳；攻击者进入一臂距离；接触发生在明确前臂、腕部、肩部或兵器点；反击由支撑脚经髋腰传至肩臂。
- **受力与终点**：接触后双方按同一力向退开，各自重建架势。
- **性格覆盖**：冷静者以小幅格挡和最短反击；暴烈者预备短、发力大、硬停；受伤者保护伤侧并减少大幅扭腰；敏捷者用换步和闪身，不增加多余招式。
- **古装可生成句式**：

```text
{{A}}以{{前导脚}}前置、降低重心，{{B}}从一臂距离完成一次{{攻击}}；{{A}}在{{明确接触点}}完成格挡，力量由支撑脚经髋腰传至肩臂，随即{{一次反击或推开}}，双方按受力方向各退半步重新立稳，衣袖和发丝只在撞击后延迟半拍摆动。
```

- **AI 风险**：连续乱打、多人肢体纠缠、武器穿身、关节反折、无接触即飞退、反向受力、一步内瞬移换位。

### A06 手部动作与特写

- **适用**：握拳、颤手端杯、擦泪、递物、撕信、执笔、拔剑/刀、交握、掌掴、抚脸。
- **通用控制**：锁定左右手、腕部朝向、配饰和道具；腕部先稳定，五指按自然顺序发力或松开；建立唯一接触点后再移动物体。
- **性格覆盖**：克制者只用指节和指尖泄露情绪；暴烈者握力大、指节发白；温柔者以指腹先接触；虚弱者腕部轻颤、抓握不稳；权势者动作少而精确。
- **古装子句库**：
  - 握拳：`四指依次收拢，拇指压在食指与中指外侧，指节发白，腕部保持中立。`
  - 颤手端杯：`指腹扣住瓷盏，腕部小幅颤动，液面先起涟漪，再从杯沿溢出少量。`
  - 擦泪：`指背从外眼角轻带至颧侧，避开眼球，面颊仍留一线泪痕。`
  - 递信物：`递出者托住玉佩或发簪底部，接取者握稳后，递出者才缓慢松指。`
  - 撕信：`双手分持信纸两侧反向用力，裂口从纸边开始并持续扩大，纸屑随后落下。`
  - 执笔：`非惯用手压住纸面，惯用手悬腕竖笔，笔锋触纸后停顿，墨迹沿宣纸纤维缓慢晕开。`
  - 拔剑/刀：`辅助手固定鞘口，主手沿鞘的轴线抽出，刃身露出后才出现冷光。`
  - 交握：`两只手各五指清楚、交错相扣，腕线自然，手掌不融合。`
  - 抚脸：`指尖先触颧侧，掌心随后轻贴但不压进面部，再沿面颊缓慢滑开。`
- **古装可生成句式**：

```text
手部特写先锁定{{左/右}}手、腕部朝向、指环/护腕与{{道具}}；手腕保持稳定，五指按自然顺序完成{{收拢/松开/接取/触碰}}，在{{唯一接触点}}停半拍，动作结束后指尖最后回收，道具与配饰全程不换侧、不变形。
```

- **AI 风险**：多指少指、畸形关节、左右手或饰品变化、手掌穿物、杯剑信物变形、无接触即带动物体。

### A07 饮茶饮酒

- **适用**：试探、沉思、压怒、决断、掩饰眼泪、宴席交锋。
- **动力链**：指腹扣杯沿或杯身，肘弯曲、腕保持水平，杯离桌；杯沿近唇停半拍，小口饮下，喉结轻滚；呼气后落杯，杯底触桌，指尖最后松开。
- **性格覆盖**：雅致者动作慢、杯身平稳；粗粝者握杯更实、落杯较重；多疑者饮前停顿并观察；决绝者饮尽后干净落杯；悲恸者腕部轻颤但不让杯穿唇。
- **古装可生成句式**：

```text
{{角色}}以{{左/右}}手指腹稳扣{{白瓷盏/酒爵}}，肘部弯曲将杯沿送至唇边停半拍，目光仍停在{{对象}}；小口饮下，喉结轻滚，呼气后垂腕将杯底落回原位，指尖最后松开，杯底轻响的同时眼神由{{前态}}变为{{后态}}。
```

- **AI 风险**：杯体变形、手指穿杯、杯沿穿唇、液体逆流或穿透、杯子瞬移、吞咽与饮下不同步。

### A08 转身回头

- **适用**：决绝离开、蓦然回首、被呼唤后侧脸、回头一笑、战后警觉。
- **完整转身动力链**：支撑脚掌转向，膝髋带动骨盆，腰背和肩线跟进，头最后转。
- **被叫停回头**：脚步和肩先停，眼睛先移，颈部只转到自然角度；身体可仍保持原朝向。
- **余势与终点**：发丝和袍摆迟后半拍越过运动方向再回落；重心重新落稳。
- **性格覆盖**：决绝者转身干净且不回望；警觉者眼先扫、头快转；克制者肩先停、缓慢露出半张侧脸；受伤者减少髋腰幅度，用上胸和目光完成。
- **古装可生成句式**：

```text
{{角色}}脚步先停，支撑脚掌转向，髋腰带动肩线转过半拍，头部最后回转；发丝与袍摆滞后摆过再回落，目光在露出侧脸时准确锁定{{对象}}，转身结束后重心重新落稳。
```

- **AI 风险**：头颈旋转 180 度、头先转而躯干融化、脚底原地滑旋、衣发提前反向、发丝穿脸或穿簪、回头时五官漂移。

### A09 双人对峙

- **适用**：谈判、质问、身份压制、旧怨相见、出手前僵持。
- **起始**：两人分立画面左右，相隔一臂半，双脚钉住，肩线相对，目光沿同一轴锁定。
- **升级动作**：只允许一次下颌微抬、手指收紧、重心前压或半步逼近；另一方用呼吸、下颌或重心回应。
- **性格覆盖**：权势者挺直、下颌微抬、只半步施压；隐忍者不后退，以手指收紧泄露情绪；暴烈者肩颈紧但暂不出手；虚弱者守住距离、用目光代替逼近。
- **古装可生成句式**：

```text
两人分立画面左右，相隔约一臂半，脚步钉住、肩线相对，目光沿同一视线轴锁定；{{A}}以{{下颌微抬/手指收紧/半步前压}}施压，{{B}}只用{{呼吸停顿/下颌绷紧/重心不退}}回应，距离与左右站位全程不漂移。
```

- **AI 风险**：人物换边、越轴、视线错位、无因贴近、五官互换、服装镜像、武器持手变化。

### A10 双人诀别

- **适用**：雨夜离开、放手、错过、决裂、无法说出口的挽留。
- **动作链**：离开者目光锁前、重心前移并连续走开；留下者原地屏息，手臂伸至半途，指尖张开，停在离后肩半臂处，再慢慢收回身侧；双方距离持续增加。
- **性格覆盖**：决绝者步速稳定、全程不回头；不舍者步幅小但不停止；克制挽留者只伸半臂；冲动者先迈半步又钉住；悲恸者收手后肩线下沉、长吐气。
- **古装可生成句式**：

```text
{{A}}背向{{B}}沿{{宫道/长廊/雨湿青石巷}}一步步离开，重心持续前移、全程不回头；{{B}}留在原地，吸气时伸手至半途，指尖停在距其后肩半臂处，随后慢慢收回贴近身侧，肩线下沉，二人距离持续拉开。
```

- **AI 风险**：手臂拉长、未迈步却瞬间远离、离开者突然换方向、雨水或湿袍穿体、伸手与收手循环重复、人物左右换位。

### A11 重逢拥抱

- **适用**：久别重逢、死里逃生后相认、雪地或城门相见。
- **动作链**：认出对方、瞳光变化、脚步顿半拍；随后加速靠近；承接者前后错步张臂，接触瞬间屈膝吸收冲力；一臂环肩、一臂托上背；抱紧、下巴轻抵发顶；对方埋肩、肩膀微颤。
- **性格覆盖**：外放者停顿短、靠近快；克制者先确认目光再走近，拥抱更慢；受伤者不奔跑，由对方主动靠近承接；权势或矜持者先僵住，手臂晚半拍才环上。
- **古装可生成句式**：

```text
{{A}}在{{城门/驿站/宫道/雪地长街}}认出对方，眼睛骤亮、脚步顿半拍，再沿固定方向奔近；{{B}}双脚前后错开、张臂承接，接触瞬间屈膝吸收冲力，随后一臂环肩、一臂托住上背，将{{A}}抱紧并下巴轻抵发顶；{{A}}把脸埋入肩窝，肩膀微颤，二人的手位保持不变。
```

- **AI 风险**：高速撞击穿模、双脚离地漂浮、承接者后退方向错误、多手多臂、脸部融合、接触后身高突变。

### A12 双人掌掴

- **适用**：冲突高潮、愤怒失控、受辱反击、关系断裂。
- **起始锚点**：明确施打者左右站位、施打手和受击者的脸侧；双方脚底先落稳。
- **动力链**：施打者吸气，肩带动上臂，肘再带腕，张掌沿单一弧线落下；掌心形成唯一脸颊接触后顺势掠过即停。
- **受力与余势**：受击者头先沿受力方向偏转，肩线晚半拍跟随，发丝随后甩开再落回；施打者收手至身侧，胸口起伏、指尖微颤。
- **性格覆盖**：暴烈者预备短、弧线大、硬停；克制者迟疑半拍才落掌，动作后手抖更明显；决绝者动作干净、不重复；受伤或虚弱者幅度较小，更多依赖肩肘而非全身旋转。
- **古装可生成句式**：

```text
{{A}}重心落稳，吸气后肩带动上臂、肘再带腕，张开的{{左/右}}手掌沿清楚弧线落向{{B}}的{{左/右}}脸颊；接触后手掌顺势掠过即停，{{B}}头部沿受力方向偏转、肩线晚半拍跟随，发丝随后甩开再落回；{{A}}收手至身侧，胸口起伏、指尖微颤，双方站位不换。
```

- **AI 风险**：左右脸错位、手掌穿头、手臂拉长、头颈过度甩动、整个人无因旋转、掌掴循环重复、双方换边。

## 10. 精简负面约束库

### 10.1 通用短负面

```text
禁止同手同脚、脚底滑移或离地漂浮；禁止关节反折、手指增减、身体/衣袖/兵器/道具穿模；禁止左右手和人物站位互换、道具变形消失、接触点漂移、受力方向错误、动作重复；禁止头颈过度旋转和发丝衣摆无因提前摆动。
```

### 10.2 选择规则

- 每镜只选与当前动作最相关的 3-6 条，不把整段通用负面机械粘贴到所有镜头。
- 手部镜头优先：五指数量、关节、持物手、配饰和道具形态。
- 走跑镜头优先：支撑脚、脚底摩擦、对侧摆臂、移动方向和衣发惯性。
- 双人接触优先：人物换边、距离突变、接触点漂移、身体穿透和受力方向。
- 转身掌掴优先：头颈角度、脸侧、施打手、脚底滑旋和发丝延迟。
- 近战优先：一镜一主事件、关节、武器接触点、退步方向和位置连续。

## 11. 交付验收

交付前逐镜检查：

- [ ] 是否只有一个主要动作事件，并拆成 3-5 个可见状态？
- [ ] 是否完整包含起始锚点、准备、动力链、主动作/接触、受力响应、余势和回收/终点锚点？
- [ ] 是否写清支撑脚、重心路径、移动方向和终点落位？
- [ ] 肩胯、肘腕、手指是否按自然关节顺序参与，而不是手臂孤立甩动？
- [ ] 视线是否先后明确，呼吸是否服务于准备或回收？
- [ ] 双人动作是否写清开场距离、主动者、唯一接触点、受力方向和结束距离？
- [ ] 左右站位、左右手、持物手、脸侧、兵器侧和配饰是否跨镜一致？
- [ ] 衣摆、袖口、发丝、佩饰、液体是否晚于主动作形成余势？
- [ ] 人物性格是否通过速度、幅度、重心、视线、呼吸、手部、距离或回收至少两个参数可见化？
- [ ] 是否删除所有“或/均可/任选”、未替换占位符和互相冲突的动作命令？
- [ ] 是否已把场所、灯具、路面、器物和服装全部转译为古装语境？
- [ ] 是否只选择本镜必要的 3-6 条负面约束？
- [ ] 每个声明镜头是否先按 `镜头号→景别→焦距→光源→机位/运动→焦点/景深` 写规范头部，再写完整表演/动作/承接，且镜头数等于镜头头部数？

验收失败时，优先减少同镜动作数量并恢复连续性锚点；不要用更多形容词掩盖物理关系不清。
