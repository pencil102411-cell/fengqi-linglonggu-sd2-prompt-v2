# 东方玄幻真人电视剧视觉母版

## 用途与所有权

本参考为每个根据当前提供的人设、场景、剧情、文字分镜或实际参考（任一来源或组合）直接交付的《风起玲珑骨》Seedance 2.0 / 2.5 完整提示词提供稳定的真人东方玄幻电视剧质量基线。它把《苍兰诀》比较器中可迁移的成片机制压缩成模型可见的画面标准，但不复制该剧的演员、角色、剧情、台词、法术造型、独特场景或镜头顺序，也不把剧名作为生成器风格标签。

- 本参考只拥有真人剧质感、实体感、皮肤与服装材质、色彩和曝光层次、人物—场景融合、空间纵深、特效融合底线及质量型排除项。
- 当前用户事实、剧本事实、已通过的参考素材、场景地理和叙事光源仍然优先。发生冲突时，只替换直接冲突的母版短句，保留所有不冲突质量控制，并在后台记录 `VISUAL_MASTER_USER_OVERRIDE`。
- `narrative-lighting-design.md` 继续拥有当前场景的具体光源、世界坐标、明暗档差、控溢光、分离层和连续性；`canglanjue-episodes-01-36-visual-grammar.md` 继续拥有明确调用时的详细比较器机制；`camera-parameter-presets.md` 继续是唯一“全局共享摄影/光影母版＋逐镜头部简表”规范。
- 本母版进入既有 `全局视觉 / 材质 / 光影母版` 字段，不新增第十个内层标题，不进入逐镜头部，不在其他字段重复。

## FQ-EFTV-01 固定质量基线

没有明确用户事实或实际参考角色冲突时，将下面一整段逐字写入 `全局视觉 / 材质 / 光影母版`。`FQ-EFTV-01` 只作为后台版本标识，不得出现在生成器提示词中。

```text
高规格真人东方玄幻电视剧质感：真实演员、实体感东方古典置景与可触摸材质；皮肤保留自然肤色、毛孔和细微血色，纱、丝、绣线、旧化金属、玉石呈现真实粗糙度、透光与反射，人物服饰接受场景同一光色，禁止磨皮塑料感和抠像感。低饱和色彩、稳定黑位、高光柔和不过曝；一个有动机的世界主光塑造脸部明暗，前景遮挡、中景人物、后景建筑与薄雾形成纵深。避免手游CG、廉价棚拍、全局泛蓝、无来源双轮廓光、高饱和亮色堆叠和背景抢脸。
```

这段基线约 200 字。它是共享母版，只出现一次；不得为满足 5000 字以内的完整提示词而删除、缩成 `电影感 / 苍兰诀感 / 高级东方玄幻`，也不得逐镜重复。

## 单一视觉家族解析

固定质量基线后必须紧接一条已解析的 `本段视觉家族` 句。根据当前剧情只选择一种，不在最终提示词中保留括号、斜线、备选项或四套并列颜色。

- `高调灵境`：以珍珠白、奶油白、淡金或低饱和桃粉建立大面积明亮环境；大面积定向柔光包裹人物但保留脸部明暗、发丝、睫毛、白衣褶皱和刺绣；用一层较暗前景与浅雾保持纵深。
- `青蓝暗域`：以青黑、蓝灰、冷石或低饱和深绿建立暗部；侧光或侧逆光切出脸和肩颈，负补光保持塑形；后景只留一处低亮暖灯、门洞或冷色开口建立深度。
- `暖木人间`：以自然肤色、暗木吸光和局部暖色实景光形成落地关系；白衣不过曝，背景不全暖黄；保留一处冷窗、夜色或绿植完成色温分离。
- `临界大战`：先把环境压成灰黑、蓝黑或低饱和烟灰，只允许一种阶段性效果色；人物身份和轮廓先可读，效果光再按预兆、出生、作用、峰值、衰减改变人物和环境，结束时回到稳定世界光并留下后果。

最终句式：

```text
本段视觉家族：{一个已解析家族名}；{当前场景的具体色彩基线、主光关系、暗部信息通道、前中后景和材质结果}。
```

## 单一术法状态分支

视觉家族句后必须紧接一个且只能一个术法状态分支。不要把两条并列写入最终提示词。

- `effect=active`：只在剧情确有术法事件时写：`术法融合：术法只在剧情触发后从明确锚点出生，具前后遮挡、互动光及身体和环境响应，峰值后回落并留下可连续的残留。`
- `effect=none`：没有术法事件时写：`现实变化来源：画面变化只来自现有世界光、人物动作、衣料、道具和环境的真实物理响应，世界光位与环境色保持稳定。`

无术法分支不出现 `术法 / 粒子 / 光环 / 能量雾 / 法阵 / 结界` 等效果名词，避免负向关键词反而预激活装饰性特效；只有已复现的特效泄漏确实需要负面约束时，才在 `负面限制` 中写一个最短、针对性的限制。

## 生成器接入合同

最终 `全局视觉 / 材质 / 光影母版` 按以下顺序形成一个连续字段：

```text
FQ-EFTV-01 固定质量基线
-> 一条已解析的本段视觉家族句
-> 一条已解析的术法状态分支
-> 当前镜头实际叙事光源、世界位置、明暗档差、控溢光、分离层、曝光和材质落地
```

- 不写 `苍兰诀风格`、`复制苍兰诀`、`像某一场戏`，也不把片名当成画质快捷词。
- 有实际视觉参考图时，仍按参考职责合同绑定，例如：`东方玄幻视觉参考图（@图片 N）只锁定真人电视剧级色彩层次、光影塑形、实体置景质感、材质响应和特效融合方式，不复制原图人物身份、剧情、构图和具体法术造型。`
- 没有术法事件时使用 `effect=none` 的现实变化分支，并彻底删除镜头级特效链；不能因为东方玄幻题材自动添加装饰性特效、环境变色或震动。
- 有术法事件时使用 `effect=active` 的术法融合分支；具体源锚点、几何、路径、遮挡、互动光、身体/环境响应和残留仍写入开场、事件、物理和连续性字段。
- 场景参考图若已经锁定不同但合格的色彩或材质，不强行套用不相容的家族颜色；选择最接近且不冲突的家族句，或按用户事实局部改写该句。

- 共享 `全局视觉 / 材质 / 光影母版` 建议保持紧凑，其中固定质量基线约 200 字，家族、术法状态分支与当前光线落地只保留必要差异。若完整提示词超过 5000 字，先原位压缩重复气氛形容、分析性标签和逐镜重复母版，再合并共享光影与材质事实，直到回到 5000 字以内；不得因此拆分同一连续视频，也不得删除 FQ-EFTV-01、已解析家族、已解析术法状态、用户锁定视觉事实、台词、表演、动作、镜头转接、连续性、全局摄影/光影事实或逐镜头部字段。

- `全局视觉 / 材质 / 光影母版` 是否含完整 FQ-EFTV-01，或只对明确冲突句做了有记录的局部替换？

- 人物皮肤、妆发、服装和道具是否真正接受场景环境光，而不是漂浮在背景前？
- 有术法时是否具备锚点、遮挡、互动光和物理后果；无术法时是否没有装饰性特效泄漏？
- 返修是否保留母版版本、已解析家族和所有未经授权的视觉控制？
