## 1. 三层分层原则（单层特效 = 低质量）

```
第一层  核心介质 — 角色直接操控的能量或物质本体
第二层  边缘粒子 — 包裹核心介质的高密度粒子光晕，掩盖帧间抖动
第三层  环境交互 — 特效与周围环境的可见反应
```

三层必须同时存在，且**按此顺序落笔**。

**第一层：核心介质**

| 修仙系 | 写法 |
|---|---|
| 剑修 | 凝实的剑气自钢刃向外延伸，压缩的能量刃口表现为可见的热扭曲 |
| 雷修 | 雷电核心光柱，等离子放电通道，空气电离泛出紫光 |
| 火修 | 燃烧核心火球，过热气体聚成球体，焰心呈白炽 |
| 冰修 | 冰晶晶格成形，绝对零度的冰核，霜纹自撞击点向外蔓延 |
| 毒修 | 高浓度毒雾，荧光绿气溶胶，接触到的表面出现腐蚀痕迹 |

**第二层：边缘粒子**
> 高密度发光粒子光晕包裹住[核心介质]，粒子在边界处密度最高、向外逐渐弥散，靠这层粒子皮肤维持帧间连续性

**第三层：环境交互**
> [核心介质]命中引发[地面炸裂／空气电离／水面震荡／草木倒伏]，次级碎屑各自弹出轨迹，冲击波环在烟尘中清晰可见

## 2. 三大禁止

- 特效在主体之前自行扩散——**主体必须是驱动源**
- 同一段内堆叠两个及以上大奇观
- 镜头在奇观峰值段随机漂移

## 3. 光影绑定（特效必须照亮实物，否则是贴图）

所有特效必须有光源动机，自发光必须对主体面部、服装、地面产生可见色彩反射。

| 特效类型 | 必写的光影反馈 |
|---|---|
| 蓝紫雷电 | 蓝紫边缘光打亮侧脸，地面间歇蓝白闪光 |
| 金红火焰 | 暖橙从下方打亮角色，周围烟雾染橙红 |
| 绿色植物/毒 | 冷绿漫反射覆盖场景，皮肤轻微绿调 |
| 白光法相 | 强逆光勾勒轮廓，场景整体曝光提升 |

逐条自检：特效光是否对面部产生色彩反射？地面墙面是否有投影或染色？烟尘是否被打亮或染色？角色轮廓是否有边缘光防止融入背景？特效最亮点是否与焦点一致？

## 4. 真人写实的物理化写法（防 CG/动漫感）

真人电影感特效不能只写"光效"，必须写成摄影机能拍到的物理现象。

```
[法术介质] + [光源性质] + [真实介质反应] + [材质反馈] + [主体绑定]
```

**禁用的形容词式空话**：炫酷法术、华丽光效、强大灵力、仙气爆发、满屏能量、神秘光芒、巨大干净光环、完整发光法阵、大面积霓虹蓝光、游戏技能拖尾。

> 禁的是形容词，不是粒子本身。§1 的三层分层和 §7 的粒子皮肤都要求高密度粒子——那是写清了
> 介质、密度分布与环境反应的具体描述，与本节不冲突。

**优先写法**
- 冷白逆光穿过烟尘，光线被水汽和灰尘削弱
- 银蓝冷光沿发丝边缘闪过，照亮睫毛、脸颊、袖口和湿石板
- 烟尘被高速法器切开一道极窄空隙
- 碎符纸、石粉、水汽被短促冷光照亮
- 衣袖、发丝、阵旗被冲击波或风压拉动
- 湿石板反射冷光，裂缝中残留微弱余光

**写实约束词**
> 光在面部与衣料上的溢出符合真实光学，实拍质感的烟雾吞掉部分光晕，尘埃与水汽被冷调逆光照亮，光线穿过雾气不均匀衰减，布料质感可触，湿石板泛起反光，不出现干净的霓虹拖尾

## 5. 尺度与仪式

### 5.1 比例反差

力量感来源于角色与奇观的尺寸差。

| 级别 | 奇观 : 角色 | 适用 |
|---|---|---|
| 一般法术 | 3-5 倍 | 覆盖场景范围 |
| 大招级 | 10-20 倍 | 覆盖天际线 |
| 终极法相 | 50-100 倍 | 遮天蔽日 |

> 极端尺度反差（extreme scale contrast），高耸的神性奇观将人影衬得渺小，灵力显化达到建筑级体量

必须给出参照物（建筑、天际线、山体），否则"大"无法被看见。

### 5.2 环境物理反馈链

大型法术不能只有光效，必须触发多层环境反应：

```
气压波   → 落叶/沙尘/水面向外扩散
电磁场   → 金属武器震颤，发丝末梢竖起
重力扭曲 → 碎石悬浮，水流倒流
温度场   → 近处火焰熄灭，远处空气热扭曲
```

> 冲击波（shockwave）向外横扫，碎屑在反转的重力场中悬浮不落，空气泛起热扭曲（thermal distortion），金属器物在电磁场中嗡鸣震颤

### 5.3 微观施法仪式

起势阶段必须包含手印／眼神／生理三联：

- **手印特写**：指节用力绷紧、皮肤纹理、指间气流凝聚可见
- **眼神异化**：瞳孔收缩或异色化（金瞳／银瞳／竖瞳）
- **生理反应**：太阳穴青筋轻跳、胸腔起伏加重、发丝被气场吹动

> 手印结成的大特写，指节绷紧到皮肤被拉出纹路，指间气流可见地凝聚收束，瞳孔竖裂异化，发丝在灵气风中根根扬起

## 6. 主体保全（变身与高密度特效的头号风险）

变身与大特效最大的失败是主体与特效融合变形。

**轮廓锁定公式**
> [精确服装层次] + [发型结构] + [面部骨相]，三者在整个过程中始终清晰可辨，不被特效吞没

**强制保持**
- 剪影边缘锐利（sharp silhouette edge），不与特效糊成一团
- 发型整体结构不在特效中消失
- 眼睛颜色与瞳孔形状——面部唯一识别锚点

**粒子皮肤（掩盖帧间抖动）**
> 高密度发光粒子皮肤（particle skin）自头到脚包裹角色骨架，粒子在身体轮廓边界处最密、向外迅速稀疏，在整个运动过程中锁死剪影稳定

空间扭曲场景另加一条：明确角色在画面中的固定位置，**背景扭曲不得越过角色边界**。

## 7. 粒子体系

| 场景 | 粒子类型 |
|---|---|
| 修仙蓄力 | 白色/金色灵气粒子 |
| 邪修/魔化 | 黑紫碎裂粒子 |
| 水系法术 | 透明水雾粒子 + 折光 |
| 雷系法术 | 蓝白等离子粒子 |
| 武侠内劲 | 无色透明气流粒子（仅可见扭曲） |

**水墨体系（东方逻辑，与西方粒子二选一）**

- 介质：水墨粒子爆散，能量拖尾呈书法笔触形态，墨色如在水中溶解般化开，墨烟在失重中缓缓膨胀
- 轨迹：墨粒沿运动轨迹拖曳成线，呈笔锋散开般的飞溅，自撞击点离心扩散，墨迹在空气中留痕不散
- 渗透：墨色渗入空气介质，边缘羽化晕开，模拟宣纸吸墨的纹理，湿墨自然洇散
- 化形逻辑：以书法笔顺逐笔重构形体——先写骨架（浓墨），再填血肉（淡墨），最后勾勒衣纹（焦笔／枯笔）；飞白处墨粒飞散，浓淡层次分明

> 水墨粒子容易退化成噪点。修法：加"墨粒成团不散、聚为一体" + 明确扩散方向。

## 8. 转化介质速查（变身与化形）

| 介质 | 写法 |
|---|---|
| 碎片解体 | 身体碎裂成发光晶体碎片（crystal shards），每片有独立飞行轨迹，由外向内逐层解体 |
| 植物藤蔓 | 藤蔓自体内破出，叶脉沿皮肤表面蔓延生长，向草木形态有机转化 |
| 羽化飞升 | 发光白羽层层吞没身形，躯体在失重中消散 |
| 丝带缠绕 | 光质丝带自四肢末端向内缠绕，在汇聚点完成形态替换，光流持续流转 |
| 光膜破茧 | 白色茧状光膜包裹，表面裂纹自内部发光，爆裂后新形态自光核显现 |
| 墨色化形 | 见 §7 水墨体系，东方逻辑替代方案 |
| 神兽附体 | 虚影自四方汇聚重叠，衣摆被气场撕裂边缘，眼睛变为兽瞳，服装浮现鳞甲纹路 |

**通用约束**：转化必须有物理过渡介质，禁止瞬切；起止形态各自明确；过程中轮廓锁定不可失效。

## 9. 空间异变词库

| 现象 | 写法 |
|---|---|
| 空间折叠 | 空间折叠（spatial folding），建筑平面向灭点方向弯折，非欧几何结构（non-Euclidean geometry） |
| 引力扭曲 | 引力透镜效应（gravitational lensing），光线绕质量点弯曲，时空曲率肉眼可见 |
| 维度撕裂 | 维度裂隙（dimensional rift），现实织体上裂开可见撕口，裂口边缘泛出虹彩辉光 |
| 时间冻结 | 时间冻结（temporal freeze），粒子悬停不动，尘埃定格半空，瀑布凝固在下落途中 |
| 镜像翻转 | 镜像世界翻转（mirror inversion），倒影世界叠加于现实之上，建筑结构不可能成立 |
| 虚空吞噬 | 虚空扩张（void expansion），黑暗吞噬空间边界，视界边缘产生拉扯扭曲 |
| 埃舍尔循环 | 埃舍尔式不可能建筑（Escher-like impossible architecture），楼梯无限向上延伸，走廊看不到尽头 |
| 莫比乌斯 | 莫比乌斯式空间翻转（Möbius inversion），地面变成天花板，室内外互相翻转 |
| 递归无限 | 递归无限空间（recursive infinite space），场景内套着同一场景的缩小副本，层层退行 |

**材质异化**

| 方向 | 写法 |
|---|---|
| 固体流动 | 石头液化，固体以缓慢黏稠的方式流动，违背重力的液态岩石 |
| 液体刚化 | 水凝结成几何晶片阵列，瀑布在下落途中冻结定格 |
| 无机生命化 | 金属抽出有机卷须，钢铁如藤蔓般生长 |
| 材质自发光 | 布料自体发光（bioluminescence），织物本身成为光源，纤维间透出流光 |

## 10. 精神污染与幻觉

- **故障感**：现实故障感（glitch effect），画面浮出数字伪影，RGB 三通道分离错位，像素位移噪波，编码崩坏的块状破碎
- **双重曝光**：多重曝光叠影（multiple exposure），记忆残像如幽灵般重播，半透明人影重叠在现实画面之上
- **镜像错位**：镜像错位（mirror displacement），倒影脱离本体独立行动，影子与身体分离，镜中人拒绝复制现实动作
- **人体解构**：肢体沿违背关节结构的方向运动，身体朝向不可能成立，半透明皮肤下可见生理结构（**限幻觉/法术场景，不做血腥暴力**）

> 超现实场景里角色不能只是茫然——必须给出对异常空间的具体反应动作。

## 11. 两类特殊状态的硬约束

**时间冻结**
- 冻结与解冻必须有涟漪／波纹／光晕作为传导媒介，不能瞬间全场静止
- 被冻结角色的眼珠与呼吸可微动，保持"人"的质感而非雕塑
- 自由行动者必须与冻结环境互动（拨开悬浮水滴、身体绕过静止碎屑），强化时间差违和感

**分身／身外化身**
- 分身"剥离"必须有物理过渡介质（光线折射／水纹涟漪／烟雾抽离），禁止瞬切出现
- 每个分身必须有独立动作目的，不做复制粘贴站桩
- 本体在分身期间维持结印或定身姿态，不与分身同时行动
- 与"影子分裂出反色对立形态"是两回事：前者是相同形态的数量压制，后者是镜像对立

## 12. 精准小法器（小目标切割）

法术目标很小时（发绳、符纸、手腕、发簪、铃铛、剑穗），**不要用大飞剑或大光刃**——模型会理解成大范围攻击。改用小型点状法器，并写清尺寸、轨迹、命中点和禁止误伤区域。

```
[尺寸] + [材质] + [飞行轨迹] + [命中点] + [禁止误伤区域] + [物理结果] + [穿出/消散]
```

**拆解顺序**：锁定目标点 → 写轨迹 → 写接触 → **写排除** → 写反应 → 写结果

**示例（断束飞针）**
> 一枚小型暗银墨蓝飞针从烟尘中高速掠来，约10厘米长、竹签粗细，三棱细锥形，外层贴合极薄冷蓝灵气膜；飞针以切线轨迹精准命中发髻根部浅蓝白发绳结，针尖只切断发绳纤维，不触碰皮肤、不削断头发；断裂布丝向两侧弹开，发髻轻微震动，几缕发丝被针风拉开，飞针穿过断口飞出画面。

**头发散开必须写过程，不能只写结果**
> 发绳断裂后，发髻外层先松动，几缕黑发从发髻边缘滑落，随后内层发束失去固定，一层一层垂下，被风压吹得凌乱铺向脸侧、肩线和纱袖。

## 13. 专项失败对照

| 症状 | 根因 | 修法 |
|---|---|---|
| 特效光污染主体 | 亮度覆盖轮廓 | 加边缘光锁定，剪影在特效前保持锐利 |
| 主体在特效中消失 | 无轮廓锁定 | 加粒子皮肤 + 服装/发型精确描述 |
| 奇观互相抢戏 | 一段多个大效果 | 每段只留一个奇观阶段 |
| 变身后脸变形 | 无面部锚点 | 锁五官特征与瞳孔形状 |
| 法术像 PPT 贴图 | 缺环境交互 | 补三层：核心介质 + 边缘粒子 + 环境反馈 |
| 特效无力感 | 无比例反差 | 加建筑或天际线作参照物 |
| 空间扭曲后主体丢失 | 背景扭曲越界 | 固定角色画面位置，扭曲不越过角色边界 |
| 帧间闪烁抖动 | 高速段无粒子皮肤 | 补粒子皮肤包裹 |
| 真人特效变成 CG/动漫感 | 只写光效本体 | 改写为烟尘、水汽、湿地面、衣料、皮肤反射等可拍到的物理反应（见 §4） |
| 小目标命中不准 | 法器尺度过大 | 换小型点状法器，写清尺寸、切线轨迹、命中点、禁止误伤区（见 §12） |
| 光影无动机 | 特效光未绑定 | 补[特效光颜色]映照在面部与地面上 |
| 水墨粒子变噪点 | 密度描述不足 | 加"墨粒成团不散、聚为一体" + 明确扩散方向 |
