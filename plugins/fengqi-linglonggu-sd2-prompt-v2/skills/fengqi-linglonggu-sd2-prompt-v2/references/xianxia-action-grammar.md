## 1. 三条核心美学

**空间借力（wire-fu）**：角色在三维空间的移动必须有踏点与借力，不能凭空平移。
> 轻点水面 / 踩踏碎裂桌板 / 沿柱奔跑 / 踩肩借力 / 脚踏空气涟漪 / 踩在香炉边缘借势

**介质破坏**：用环境破坏具象化内力与打击重量。
> 剑气激起水幕 / 爆裂木屑 / 气流卷起枯叶 / 斩断飞檐瓦片 / 地面炸裂烟尘 / 柱身崩裂

**变速对比**：拒绝全程匀速。兵刃相交、水花炸裂的瞬间放慢到可逐颗分辨；人物突进、拔刀的瞬间快到只见残影。变速点写成变速过渡（speed ramp transition），速度渐变不可突变。

> 不写升格倍率、帧率、精确圈数——没有控制接口。慢速一律写成"能看清什么"：火星逐颗可辨、
> 刃口反光的移动清晰可见、衣料褶皱缓慢展开。

## 2. 画面清晰法则

- 固定指令：运动模糊只作用于背景（motion blur on background only）
- 角色面部与武器边缘始终锐利
- 高速段至少加入一项：变速过渡（speed ramp）／动态运动模糊（dynamic motion blur）／能量拖尾（energy trails）

运动模糊分层：

| 层级 | 模糊程度 | 对象 |
|---|---|---|
| 零模糊 | 绝对清晰 | 面部、眼神 |
| 微模糊 | 极轻拖影 | 躯干、服装 |
| 中模糊 | 明显残影 | 武器轨迹、粒子尾迹 |
| 强模糊 | 大面积 | 背景、次要环境元素 |

## 3. 受力与反馈

### 3.1 节奏结构

慢（长蓄力前摇建立张力）→ 极快（出手瞬间带残影）→ **微停顿（hit stop）**→ 余韵（环境与粒子收束）。

微停顿是力量感的真正来源：命中瞬间画面几乎停住，汗珠、碎屑、发梢悬在半空后才继续下落。

### 3.2 受击反馈

不要只写"A打B"，必须写受击方的状态：

- 命中瞬间重心失衡后倒
- 受击侧脸颊肌肉被冲力向后带开，头颈随力偏转，汗珠与唾沫脱离面部
- 向后抛飞 / 砸入地面 / 撞出真实反作用力

> **禁止写「面部扭曲」「面部形变」。** 面部崩坏是 AI 视频最高频的失败模式，而 `负面限制` 里通常
> 正写着不换脸、身份不漂移——正文再出现这四个字等于给模型发许可证，两条指令打架，整条报废。
> 要表达受击，就写具体的肌肉与力的方向。

### 3.3 环境联动

让环境跟着受力动：脚底尘土飞扬 / 空气炸开冲击波（shockwave）/ 碎石飞溅 / 瓦片断裂 / 地面砸坑 / 柱身崩裂 / 铁器爆出火花。

### 3.4 空间关系

提示词必须写明双方的立体关系，不能只有平面左右：

- **上下**：台阶下与屋顶的立体攻防；半空与地面的呼应；高处夹击低处
- **前后与接触**：背靠背防御；踩肩借力腾空；从背后突袭转正面格挡

## 4. 轨迹可视化（解决瞬移＝跳帧）

- ❌ 禁止写：A 瞬移到 B 面前攻击
- ✅ 必须写：A 点 → **轨迹显现**（残影／烟雾／雷电／流光）→ B 点落位 → 命中定格

必注入：能量拖尾（energy trails）、动态运动模糊（dynamic motion blur）、轨迹连续无断点、落点之间有可见路径残留。路径形态选一种：Z 字折线／S 形曲线／折叠路径。

## 5. 追逐的多段衔接

单镜内连续穿越多个空间时：

```
[段落A终点即段落B起点] + [速度渐变] + [地形/障碍切换] + [镜头锚点不变]
```

**三条约束：**

- 每段衔接处必须有**过渡介质**（飘过的竹叶／翻飞的衣摆／溅起的水花），不能硬切
- 速度必须在过渡介质处渐变，变速点写成变速过渡（speed ramp transition）
- 镜头锚点全程不变：FPV 即全程 FPV，背跟即全程背跟

**写法示例（竹林→悬崖→水面）**
> 追逐始于密竹林，第一人称视角（FPV）在角色身后跟随，角色在竹竿之间腾跃借力。竹林渐疏，地形过渡到崖边——角色不作停顿直接跃出悬崖，镜头随之下俯跟坠，变速过渡（speed ramp）进入慢动作。角色撞入水面，镜头穿过溅起的水花转为水下跟拍，气泡与碎屑在身后拖成一条尾迹。

## 6. 轻功与飞行

**轨迹定制**：力量型走 Z 字折线／二段弹射；飘逸型走螺旋上升／S 形曲线。

**三大物理反馈缺一不可：**

1. **起跳反作用力**——地裂／水花／烟尘下压，瓦片崩碎
2. **空气阻力**——发丝后拉、衣摆延展、披风贴体
3. **空中借力点**——脚踏空气涟漪／虚空莲花／踩踏实体（水面、柱顶、香炉边缘）

缺第一条飞行就像被吊起来，缺第二条像静止贴图，缺第三条像平移。

## 7. 御剑飞行（本文件最实用的一节）

御剑不能只写"御剑飞行、速度很快、衣袂飘动"——那会变成无聊的空中平移。真实感来自五层互动。

### 7.1 五层互动

**人物**：身体微前倾，重心随飞剑转向轻微调整；衣袖、披帛、发丝被风压向后拉直；中近景可加"短暂看向镜头再看回前方"的眼神互动。避免双臂张开、挥手、舞蹈动作、僵直站立。

**飞剑**：必须影响空间，不能只是脚下光条。切开云雾／压出水池波纹／擦过石柱或山壁带起薄雾；转向时剑身微侧倾，剑尾留细长流光。

**环境**：速度感来自近景参照物，不来自"很快"两个字。每段高速飞行至少两类近景互动——石柱从镜头两侧高速掠过／山壁近距离擦过／云雾被劈开／水面被风压推开／桥柱台阶形成纵深视差。

**镜头**：镜头必须参与飞行，不能只旁观。正前侧方贴身跟拍，或从前侧方沿平滑弧线滑到背后侧方；披帛、云雾、石柱可短暂扫过前景形成遮挡。背景运动模糊，人物与飞剑保持清晰。

**光影**：水池冷蓝反光闪过脸侧／云影或山壁阴影短暂压暗人物／穿出云层后逆光勾亮轮廓／飞剑灵光照亮鞋底、衣摆下缘与近处薄雾。

### 7.2 飞剑的三重身份（最易写错的一格）

**飞剑既是武器也是载具，同一柄剑在不同段落承担不同身份。** 模型的失败点不是"剑不该在手里"，而是**同一段里兼任两者**——脚下踩着剑、手里又握一柄，或身份无过渡地跳变。按段落锁定身份，切换必须写出交接动作。

| 段落性质 | 剑的身份 | 必写 |
|---|---|---|
| 飞行段（穿行、掠水、破云） | 脚下载具 | 剑横向悬浮于双脚正下方承载体重，双脚清楚踩在剑身中段，**手中无物** |
| 近战段（落地接战、格挡、劈刺） | 手中武器 | 剑在掌中，握位与劈刺方向清楚，**双脚落地或另有借力点**，不再踩在剑上 |
| 离体飞击段（御剑攻击、飞剑取敌） | 离体法器 | 剑**既不在脚下也不在手中**，脱手远程飞击；人站定或另有踏点，手结驭剑指诀、视线锁住剑的去向，飞行轨迹全程可见 |
| 交接段（起飞、落地、放剑、收剑） | 过渡中 | 必须写出交接动作本身 |

> **御剑攻击属于离体飞击，不是手持劈刺。** 把"御剑攻击"写成握剑挥砍，动作性质整个反了。
> 判断只看一件事：**这一段剑离不离手。**

三种身份的落笔示例：

> **飞行段**：脚下是一柄横向悬浮的细长银白飞剑，始终位于双脚正下方，承载其全部体重。双脚清楚踩在剑身中段，手中没有任何物品。
> **近战段**：自剑上跃起落于石阶，飞剑同时脱离脚下、旋身入掌，反手握住剑柄，剑尖斜指地面。
> **离体飞击段**：立于石阶不动，右手二指并拢竖于胸前作驭剑指诀，目光锁住前方；飞剑离她三丈之外自行转向，剑身贴着水面高速掠出一道笔直白痕，直取敌阵。

### 7.3 交接动作词库（省了就是瞬移）

| 身份切换 | 交接动作 |
|---|---|
| 武器 → 载具（起飞） | 剑自掌中脱手 → 横向悬停于脚前 → 人踏上剑身 → 剑携人升起 |
| 载具 → 武器（落地接战） | 人自剑上跃下 → 剑同步脱离脚下 → 旋身入掌，反手握住剑柄 |
| 载具 → 离体（空中放剑） | 足尖点剑身借力弹起、落于实处 → 剑自其下方抽离 → 悬停身侧待命，剑尖已指向目标 |
| 武器 → 离体（放剑） | 掌心一送，剑脱手前冲 → 手指并作指诀，视线锁住剑的去向 |
| 离体 → 武器（收剑） | 飞剑回旋掠回 → 抬手截住剑柄 → 顺势下压，剑尖斜指地面 |

## 8. 视觉符号池（按需取 2-3 个，不堆叠）

超高速转体特写 / 兵器高速碰撞火花 / 兵器脱手旋转慢镜 / 广角变形拉出超常纵深（wide-angle distortion）/ 慢动作布料层层延展 / 多角度碎片爆破 / 飘逸纱幔与金属冷光对撞 / 高速划过的竹叶、雪花、花瓣 / 逆光剪影下的搏杀 / 烟尘中若隐若现的刀光

> 只取视觉符号本身，**不写导演名或流派名作为风格标签**——那是抽象标签，模型执行不了，
> 且与本项目"不用片名/导演名当风格捷径"的规则冲突。

## 9. 专项失败对照

| 症状 | 根因 | 修法 |
|---|---|---|
| 画面软、无力感 | 缺停顿与反作用 | 加 hit stop + 受击方抛飞 + 冲击波 |
| 速度感不足 | 无参照物 | 背景运动模糊 + 环境破坏 + 变速过渡 |
| 瞬移像跳帧 | 无中间态 | 补轨迹可视化（残影/烟雾/流光）+ 每落点定格 |
| 飞行像平移 | 无物理三反馈 | 补起跳反作用力 + 风阻服饰延展 + 空中借力点 |
| 御剑无聊 | 只有主体没有互动 | 加人物看镜头/重心微调 + 飞剑压水雾擦石柱 + 近景参照物掠过 + 前景遮挡 |
| 飞行段飞剑跑到手里 | 身份未按段锁定 | 按 §7.2 三重身份表锁定，切换处补 §7.3 交接动作 |
| 凭空飞行无真实感 | 无踏点 | 加踏点（水面/柱顶/虚空涟漪）+ 起飞地面破裂 |
| 镜头乱飘 | 多锚点 | 锁单一锚点（背跟/FPV/受击跟随），全程不换 |
| 动作抢戏 | 一段塞多个目的 | 只保留本段核心动作目的，删次要动作 |
| 主体融合变形 | 权重不明 | 明确主攻者/受击者视觉权重，弱化群演与环境物件 |

## 10. 术语对照

**镜头**：越肩跟拍 over-the-shoulder tracking / FPV 追逐 FPV chase / 侧向平跟 lateral tracking / 俯拍拉远 top-down pull-back / 手持震动 handheld shake / 低角度仰拍 low angle / 环绕运镜 orbit shot

**节奏**：微定格 hit stop / 变速过渡 speed ramp / 子弹时间 bullet time / 一镜到底 one continuous shot

**反馈**：冲击波 shockwave / 碎屑飞溅 debris burst / 能量拖尾 energy trails / 动态运动模糊 dynamic motion blur

## 交付前自检（仅本领域，通用项见 seedance-assembly.md）

- [ ] 每个高速或瞬移动作是否有可见轨迹，而不是跳帧？
- [ ] 起跳是否有地面反作用，命中是否有受击响应？
- [ ] 飞行是否齐了反作用力、风阻服饰、空中借力点三项？
- [ ] 御剑段的剑身份是否按段落锁定，切换处是否写了交接动作？飞行段是否手中无物？
- [ ] 是否出现了「面部扭曲/面部形变」？
- [ ] 运动模糊是否只作用于背景，角色与武器边缘是否保持锐利？
- [ ] 镜头锚点是否全程单一？
- [ ] 是否混入了升格倍率、帧率、精确圈数这类无接口参数？
