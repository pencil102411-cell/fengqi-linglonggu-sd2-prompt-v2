## 1. 执行契约

1. 先确定人物、关系、场合、主情绪、反向力和结尾状态，再选预设。反向力指角色压住主情绪的原因，如“愤怒但必须守礼”“喜悦但不敢被发现”。
2. 每个镜头只选一个 M 预设作为主弧；必要时只从第二个预设借一个辅信号，不拼接两条完整弧线。
3. 每个状态只写一个主面部动作，至多再写一个生理泄露。让视线变化先发生，嘴角、下颌或呼吸随后响应。
4. 4-6 秒输出 3 个状态，6-10 秒输出 4 个状态，10-15 秒输出 3-5 个状态。一个镜头最多一次主要情绪反转。
5. 为每个镜头先锁定唯一泪态、唯一目光逻辑和唯一结尾表情；结尾必须是可维持的画面状态，不以抽象形容词收尾。
6. 把文学含义改写成可见控制。例如把“心如死灰”改成“视线失焦、嘴角归平、呼吸变浅”。
7. 让身体动作服从画幅。超近特写不写跪倒、捶地、抱膝等画幅外动作；需要这些动作时改用中近景或更宽景别。

## 2. 来源归一与正文优先裁决

把来源的正文表演段视为可见目标，把后附拆解表只视为索引。两者冲突时，保留正文中的动作、限制和终态，丢弃拆解误写。不要折中成互斥指令。

### 四项不可回退的正文裁决

1. **克制的愤怒**：使用“上眼睑轻压、目光收束、下颌紧、吞咽、呼吸回落、眼红但无泪”；禁用拆解中的瞳孔放大、瞪眼、掩面、全身发抖和泪落。
2. **男性-温柔宠溺**：使用“男方凝视对方、眉眼放松、自然浅笑、想触碰又停”；禁用拆解误写的“刚睡醒、埋进被子、只露笑眼”链条。
3. **冷静（阴狠面具剥落）**：完整模式使用“温柔笑仍在而眼底先冷 → 笑意抹平 → 新的单侧冷笑出现”。若剧情只要冷静警觉，必须在“眼底降温”处停止，不自动进入阴狠。
4. **重逢克制**：默认结尾是“转身后眼眶变红、不回头、不落泪”；只有剧情明确要求释放时才改成单滴泪。禁用拆解把泪落设成必然终态的写法。

### 其余归一规则

- 正文时长与拆解时长不同时，按当前镜头时长重新分拍，不复制任一套秒数。
- 正文人物、服装、道具与拆解标签不同时，只提炼可见表演，不继承错写身份。
- “固定近景、无手部、无泪、无台词”等硬限制高于动作建议。
- 标题与正文落点不同时，以正文可见终态重命名。例如“倔强压抑→破碎释然”的正文终态实际是含泪强撑，按 M02 使用。
- “冷静警觉”和“阴狠面具剥落”保持为两种强度，不因一个文件名而强制合并。

## 3. 最小情绪节拍

使用以下五段语法；短镜头可合并相邻段，但不可跳过结尾状态：

1. **基线**：写刺激前的默认面孔、视线落点和身体静止度。
2. **触发**：用瞬间、短促的注意力改变表现“听见/看见/认出”，优先写目光停住、聚焦或短暂避开。
3. **泄露**：让一处生理信号先暴露情绪，如下眼睑轻颤、喉头一滚、鼻息一滞、嘴角停顿。
4. **控制或转折**：让人物压回、改写或放任情绪，如垂眸再看回、慢呼气、笑意撤去、含泪强笑。
5. **落点**：指定能稳定维持的终态，如“泪悬在下睫毛不落”“唇线归平、目光冷静”“闭唇浅笑看回”。

最小节拍句式：

```text
[整数起点]-[整数终点]s [视线/注意力变化]；[一个主面部动作]，[一个生理泄露（可选）]；情绪落在[明确终态]。
```

## 4. 可见部位词库

| 通道 | 优先用语 | 中强度用语 | 限制 |
|---|---|---|---|
| 眼球/视线 | 失焦、聚焦、垂眸、看回、锁定、短暂避视 | 扫一次出口、目光下沉、追随对象 | 同一状态不可既失焦又锁定；多向乱扫只用于恐惧。 |
| 上眼睑 | 轻压、缓慢掀开、短暂闭合 | 眼裂略增、半眯 | 轻压与圆睁互斥。 |
| 下眼睑 | 一次轻颤、轻收紧、下睫毛湿润 | 两次细颤、红意加深 | 禁用高频或全程狂颤，避免闪烁。 |
| 眉 | 内眉轻蹙、单眉轻挑、眉峰略压 | 眉间短暂收紧 | 单眉挑偏得意/算计；双眉高抬偏惊吓。 |
| 鼻翼/鼻梁 | 鼻息停半拍、鼻翼轻翕一次 | 鼻翼随一次吸气收放、鼻梁轻皱 | 忍哭用鼻翼；厌恶用鼻梁，默认不叠加。 |
| 嘴角 | 对称浅扬、单侧轻挑、笑意停住、慢慢归平 | 强撑笑轻颤、笑意撤去 | 真笑让眼睑同步放松；冷笑保持眼底无暖意。 |
| 双唇 | 微张、轻抿、闭合、唇线压平 | 下唇轻颤、短暂咬住后放松 | 闭唇与台词/大笑互斥；咬唇只出现一次。 |
| 下颌/下巴 | 下颌线收紧、下巴轻收、微抬 | 下巴细颤、咬合一次 | 下巴收偏羞怯/防御；下巴抬偏自尊/蔑视。 |
| 喉头/吞咽 | 喉头轻滚一次、把话咽回 | 吞咽变重、哽住半拍 | 一次足够；连续滚动易失真。 |
| 泪线 | 眼眶浅红、下睫毛湿润 | 泪珠悬住、单滴滑落 | 遵守单一泪态，不混写无泪与泪落。 |
| 呼吸 | 屏息半拍、短吸气、缓慢呼气、轻叹 | 呼吸变浅、一次哽咽式吸气 | 先屏息、后急促；不可同拍。 |
| 头颈 | 轻偏头、垂首、回正、微抬颌、颈侧短绷 | 后撤半步、靠向支点 | 每个状态最多一个方向，不来回摆头。 |

## 5. 强度可靠性与单一泪态

### L1-L5 强度

| 级别 | 幅度 | 用法 |
|---|---:|---|
| L1 泄露 | 5%-15% | 只改变一个通道。用于高位、清冷、谋略、公开场合。 |
| L2 可读 | 15%-30% | 一个主动作 + 一个生理信号。作为默认强度。 |
| L3 临界 | 30%-50% | 只把泪线、唇颤、呼吸中的一个通道推高，其余保持克制。 |
| L4 释放 | 50%-70% | 允许落泪、笑开或一个动作爆点，只放在最后 1-2 秒。 |
| L5 失控 | 70% 以上 | 狂笑、跪倒、捶地、嘶吼。仅在剧情明确要求且景别容纳时使用。 |

### 可靠性排序

按以下优先级写动作：

`视线落点 > 眼睑张力 > 嘴角方向 > 下颌/吞咽 > 呼吸 > 泪线 > 瞳孔尺寸`

- 不单独依赖“瞳孔骤放/骤缩”。震惊改写为“目光骤停、眼裂略增、屏息半拍”；警觉改写为“目光凝实、上眼睑轻压”；认出改写为“涣散视线迅速聚焦到对方眼睛”。
- 不把“眼底有光、寒意渐浓”等抽象词当作唯一动作；至少配一个视线、眼睑或嘴角变化。

### 单一泪态规则

每个镜头先选择一个泪态合同，并让所有状态服从它：

- **T0 干眼**：不红、不湿、不落泪。
- **T1 红/湿但无泪珠**：眼眶浅红或下睫毛湿润，不形成可见泪滴。
- **T2 悬泪不落**：泪珠只停在眼缘，直到结尾仍不滑落。
- **T3 单滴泪**：先蓄水，转折后只让一滴从一侧滑落，不再连续流泪。
- **T4 决堤**：连续泪流，只用于 L4-L5 的明确崩溃镜头。

允许的推进是 `T0→T1`、`T1→T2`、`T1/T2→T3` 或 `T1/T2→T4`。一旦进入 T3/T4，不得在后文再写“始终无泪/泪未落”。同一镜头不同时使用 T2、T3、T4。

## 6. M01-M32 标准化预设

表中“禁用”同时表示不可与该预设默认弧线混写；只有用户明确改变剧情目标时才可另选预设或泪态。

| ID / 名称 | 触发 | 可见弧线 | 适用 / 禁用 |
|---|---|---|---|
| **M01 不信到悲伤落泪** | 背叛或失去被证实 | 失焦→骤然聚焦→单侧自嘲笑→笑意垮下→唇颤、单滴泪 | 适合重情、倔强、爱体面；默认 T3。高位者改用 M02；禁用同拍释然再崩溃。 |
| **M02 倔强含泪** | 认出舍不得的人或被迫告别 | 涣散→认出→垂眸压回→看回、闭唇强笑→泪悬不落 | 适合要强、守礼、外冷内热；固定 T2。禁用泪落、掩面、剧烈肩抖。 |
| **M03 克制怒意** | 受辱、被背叛却必须维持体面 | 上眼睑轻压、目光锁定→下颌紧、吞咽→慢呼气→冷静决断 | 适合高位、纪律、自尊强；T0/T1。禁用瞪眼、瞳孔放大、掩面、泪落。 |
| **M04 触物/进食悲伤** | 熟悉食物、信物或重复动作唤起思念 | 机械重复→动作慢半拍→吞咽/鼻翼泄露→仍继续→泪在下一次动作时落 | 适合以忙碌压情绪者；T3/T4。禁用无道具空演和连续多次情绪反转。 |
| **M05 麻木自嘲冷笑** | 尊严受损、地位崩塌、被当面羞辱 | 失焦木然→单侧嘴角极慢抬起→头回正、下巴微扬→重新聚焦 | 适合骄傲失势者；T0-T2。禁用快速奸笑、露齿、眉眼含笑。 |
| **M06 深情心疼到幸福** | 确认爱人平安或被亲密小动作安慰 | 专注凝视→眼眶湿润、抿唇→微怔→对称浅笑→温柔笃定 | 适合稳定伴侣、劫后相守；固定 T1/T2。禁用泪落和单侧冷笑。 |
| **M07 爽朗大笑收束** | 熟人打趣、胜利或无防备的快乐 | 眉眼舒展、自然笑开→笑声退去→扇/手背遮口→平和眼神 | 适合直率明朗；T0。禁用冷眼、讥笑、遮口后继续大笑。 |
| **M08 从容妩媚浅笑** | 与信任或感兴趣的人建立眼神联系 | 眼神先于转头找到对方→头回正、抬颌→闭唇浅笑→轻点头 | 适合成熟、自信、掌控感；T0。禁用快速转头、露齿大笑、频繁眨眼。 |
| **M09 天真娇羞笑** | 做事时被心上人唤住 | 快速聚焦、眼底变亮→短暂避视→嘴角先弯→轻歪头看回 | 适合天真、初恋感、鲜活少女；T0。禁用多次左右飘眼和单侧冷笑。 |
| **M10 端庄害羞笑** | 被熟人当面打趣或情意被点破 | 面容端正→嘴角先泄露→扇/帕遮唇、垂眸→从边缘看回 | 适合守礼、内向、外冷内软；T0/T1。禁用“始终直视”与持续垂眸并写。 |
| **M11 微醺浅笑** | 微醺或半梦中认出信任的人 | 闭眼含笑→极慢睁眼、短暂失焦→聚焦→闭唇软笑加深 | 适合慵懒、柔软、亲密；T0/T1。禁用张嘴大笑、快动作和醉态失控。 |
| **M12 暗爽** | 仇人出丑、计策小成或听到暗中好消息 | 垂眼用道具遮唇→眼尾短暂弯起→恢复如常→快速偷瞄 | 适合机灵、会藏情绪者；T0。禁用自动转冷笑或恶毒表情。 |
| **M13 纯悲伤压缩** | 短镜头内突然接受痛苦事实 | 失焦→勉强强笑→笑意垮下→眼红、单滴泪 | 适合 4-6 秒反应镜头；T3。与 M01 二选一，禁用再加长链条。 |
| **M14 得意不张扬** | 掌握证据、先手或胜局 | 单眉轻挑→目光从证据移向对手→单侧嘴角慢扬→轻歪头持有 | 适合聪明、自信、掌控型；T0。禁用蹙眉、低头羞笑和夸张挑眉。 |
| **M15 复仇冷意** | 旧仇对象出现或复仇时机到来 | 平静抬眸→单侧嘴角只动一点→上眼睑轻压、眼神降温→锁定 | 适合长期筹谋、纪律型复仇者；T0。禁用狂怒、露齿和无依据台词。 |
| **M16 嫉妒下的体面** | 目睹心上人与他人亲近 | 原笑冻结→短暂移开又看回→吞咽、唇线变平→礼貌笑反而加深、眼底变冷 | 适合高位、公开场合；T0/T1。禁用当众泪崩和同时转身。 |
| **M17 谄媚面具剥落** | 不再需要讨好或察觉对方失去价值 | 堆笑→等待时僵住→笑纹一丝丝撤去→目光凝实、单侧冷弧 | 适合两面派、老练官僚；T0。禁用青筋、皱鼻、眯眼、挑眉同时出现。 |
| **M18 初见心上人的娇羞** | 意外看见思念或倾慕的人 | 顿住屏息→眼神变软→垂眸偷看→短暂避开→吸气后重新对视 | 适合感情经验少、礼教约束强；T0/T1。禁用圆睁、狂颤、反复偷看。 |
| **M19 决绝** | 生死选择、背水一战或牺牲决定 | 恐惧只泄露一瞬→闭眼长呼气→睁眼稳定→单侧冷笑一闪即收→目光落定 | 适合战士、纪律型角色；T0/T1。禁用把冷笑当结尾，最终必须回到决心。 |
| **M20 绝望坍塌** | 唯一希望或至亲被确认失去 | 僵住、微张唇无声→失焦→小幅摇头一次→下巴颤、泪落→肩线塌下 | 适合即时噩耗；T3/T4。超近景禁用跪倒/抱膝，需另换景别。 |
| **M21 恐惧** | 直接威胁、无路可退 | 屏息、眼裂略增→视线扫一次退路→后撤受阻→下唇颤、头颈后缩 | 适合失去掌控者；T0-T2。禁用“瞳孔到极限”、持续乱扫和立刻缩成一团。 |
| **M22 温柔假面转阴狠** | 秘密暴露或决定不再伪装 | 暖笑仍在而眼底先冷→笑意抹平→新的单侧冷笑→轻抬下巴 | 适合伪善权贵、腹黑反派；T0。只要警觉时在第二步停止；禁用默认全程凶狠。 |
| **M23 冷笑断裂** | 创伤记忆、自嘲或痛苦逼近失控 | 失焦→单侧冷笑生成→弧度短暂加深→突然停住→唇颤、吞咽、再失焦 | 适合创伤型崩溃；T0-T2。默认禁用狂笑和面部痉挛，除非明确要 L4。 |
| **M24 外化型悲痛** | 得知残酷真相且无力挽回 | 空洞、张口无声→唇与呼吸失控→一个物理爆点→低头、肩线抽动 | 适合习惯压抑后行动释放者；T3/T4。物理爆点交给肢体语法；超近景禁用捶地。 |
| **M25 得逞邪笑** | 陷阱奏效、猎物入局 | 漫不经心垂眸→先抬眼锁定→单侧嘴角慢勾→停顿回味、控制感落定 | 适合谋士、反派、猎手型；T0。禁用不可见舌部动作和自动补台词。 |
| **M26 温柔宠溺** | 看见亲近者疲惫、可爱或毫无防备 | 侧目关注→眉眼放松→对称自然浅笑→想触碰又停→轻叹 | 适合温柔、尊重边界、熟稔关系；T0/T1。禁用拆解误写的睡醒藏笑链。 |

## 7. 人物姓名与气质路由

### 姓名命中流程

1. 先读 [character-performance-bible.md](character-performance-bible.md)，用用户给出的姓名解析 `canonical_id + timeline_overlay + relation_overlay`；同时处理别名、歧义称谓、身份阶段和关系对象。命中后不得用性别刻板印象覆盖角色档案。
2. 读取底色与公开面具、欲望恐惧、默认节奏，以及眼神、嘴角、呼吸、手部、姿态、社交距离、阶段变体、关系变体和禁忌。
3. 从剧情提炼一个主情绪和一个反向力，再选一个预设。例如“愤怒 + 必须守礼”选 M03，“喜悦 + 不敢被发现”选 M10/M12。
4. 为整条表演弧选择 2-4 个可见通道；每个状态只激活一主一辅，不让四个通道同时变化。
5. 先应用角色的强度上限，再应用场合限制。高位、公开场合、受伤体虚通常下调一级；独处、最后防线断裂才允许上调。
6. 未命中角色档案时，遵守人物圣经的资料不足规则，只根据用户已给信息建立临时气质标签；不要臆造固定性格并写成角色设定事实。

## 8. 硬互斥与过演防护

### 硬互斥

同一状态出现下列组合时必须二选一：

1. 失焦 vs 锁定同一点。
2. 上眼睑轻压/眼型克制 vs 双眼圆睁。
3. 始终直视 vs 垂眸、侧看或扫视；改成“主要直视，中间短暂避开一次”。
4. 闭唇不露齿 vs 说台词或张嘴大笑。
5. T0/T1/T2 的无落泪终态 vs T3/T4 的泪落。
6. 身体纹丝不动/无手部 vs 掩面、握拳、后退、转身。
7. 固定超近特写只演脸 vs 跪倒、捶地、抱膝等完整肢体动作。
8. 同一拍屏息 vs 急促呼吸；先屏息，下一拍再变浅快。
9. 冷笑“不入眼” vs 眉眼同步含笑。
10. 同一拍下巴内收 vs 下巴上扬。
11. 一个嘴角归平 vs 同时继续扩大笑容。
12. “无台词” vs 可见口型持续说话。

### 过演防护

- 每个状态只保留一主一辅；不得同时堆瞳孔、眉、鼻翼、嘴唇、下巴和肩膀六处变化。
- 一秒内最多两个可见变化；短促触发后至少留一拍供观众读取。
- 把“狂颤、剧烈抽搐、红到滴血、放大到极限、泪如水流”降为一次轻颤、短暂收紧、浅红、眼裂略增、单滴泪。
- 冷笑/邪笑/奸笑默认只用“眼底冷 + 单侧嘴角”。不要再同时加挑眉、皱鼻、露齿和青筋。
- 害羞默认只用“一次避视 + 闭唇浅笑或道具遮掩”。不要叠加反复偷看、咬唇、缩肩和大幅脸红。
- 悲伤镜头最多一次反转。5 秒内不写“震惊→否认→冷笑→微笑→泪崩→释然→再崩溃”。
- L4-L5 只占结尾 1-2 秒；若整段都高强度，先重写为 L2 起步。

## 9. 冲突裁决顺序

多来源或多预设冲突时，按以下优先级裁决，低优先级不得推翻高优先级：

1. 用户本次明确要求与禁令。
2. 角色表演档案中的既定性格、关系、伤病与公开禁区。
3. 本镜头的画幅、时长、无台词/无泪/无手部等硬限制。
4. 剧情所需的最终状态：体面、决绝、崩溃、和解或伪装。
5. 来源正文中真正可见的表演目标。
6. 本文件的标准化预设与可靠性排序。
7. 来源拆解表、标题、案例身份与文学比喻。

执行裁决时：

- 删除冲突项，不写“既……又……”折中句。
- 把错配的时长重新分配，把错写的人物/场景移除。
- 先选泪态，再删除所有不兼容泪词。
- 先选目光逻辑，再删除不兼容的“始终直视/躲闪/失焦/锁定”。
- 让微表情语法控制脸部，让动作与肢体语法控制手、肩、躯干和走位；画幅无法容纳时，以画幅为准。
